Curious Differences is an original spot-the-difference game: two near-identical pictures side by side — find every hidden change before the clock runs out. Three hand-drawn scenes (Sunny Garden, The Curiosity Shop, Night Harbour), 5/7/9 differences, hints, score streaks, and synthesized sounds. Play with mouse or keyboard, no install, no network.

## Run it

```sh
python3 -m http.server 8000 --directory game
# then open http://localhost:8000 in a desktop browser
```
